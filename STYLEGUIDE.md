# Философия дизайна

Интерфейс должен создавать ощущение современного, лёгкого и дружелюбного образовательного приложения.

Минимум отвлекающих элементов.

Максимум внимания обучению.

Пользователь должен чувствовать, что он может начать заниматься уже через несколько секунд после открытия сайта.

---

# Основные принципы

- Простота
- Чистота
- Воздух
- Скорость
- Интерактивность
- Современный внешний вид

# Иллюстрации

Используем:

- современные flat-иллюстрации;
- собственные SVG;
- минимум фотографий.

Главное внимание должно быть на тренажёрах, а не на декоративных изображениях.

---

# Стиль текста

Пишем простым языком.

Без сложных терминов.

Каждый экран должен мотивировать пользователя продолжать обучение.

---

# Адаптивность

Сайт должен одинаково хорошо работать:

- Desktop
- Laptop
- Tablet
- Mobile

Mobile — обязательный режим.

---

# Производительность

Цель:

- быстрая загрузка;
- минимум зависимостей;
- минимум сторонних библиотек.

---

# Правила разработки

Не использовать тяжёлые UI-фреймворки.

Предпочитать собственные CSS-компоненты.

Каждый новый элемент должен соответствовать этому Style Guide.

---

# Главное правило

Красивый дизайн помогает пользователю.

Но дизайн никогда не должен мешать обучению.
